Firebase Cloud Messaging Setup:

This project uses Firebase Admin SDK to support push notifications. The service account key
is not included in this repository for security reasons.

1. Install Dependencies:
    - Ensure you are in the project root, then run "pip install firebase-admin"
    or "pip install -r requirements.txt" in the terminal.

2. Firebase Service Account Key:
    - Obtain the Firebase service account JSON file (shared securely).
    - Place the file in the root directory of the Flask project.
    - Ensure the filename is "serviceAccountKey.json"
    IMPORTANT:
        - This file is listed in .gitignore and should never be committed 
        to GitHub.
        - Do not rename or upload this file to the repository.

3. Running the App:
    - Once dependencies are installed and the Firebase key is in place, you can run the
    Flask app normally.
